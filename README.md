## 用法
安装 Python 3，解压后在本目录打开终端，运行：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

浏览器打开 <http://127.0.0.1:8000/>。终端按 Ctrl+C 停止。
不要直接双击 `index.html`，浏览器会限制 ES modules 和 JSON 加载。
前端不需要 npm 安装、构建步骤、后台服务、登录或密钥。
Tailwind、ECharts 和字体使用原有外部 CDN，因此完整界面与图表需要网络连接。
