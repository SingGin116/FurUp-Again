## 用法

安装 Python 3，解压后在本目录打开终端，运行：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

浏览器打开 <http://127.0.0.1:8000/>。终端按 Ctrl+C 停止。

不要直接双击 `index.html`，浏览器会限制 ES modules 和 JSON 加载。
前端不需要 npm 安装、构建步骤、后台服务、登录或密钥。
Tailwind、ECharts 和字体使用原有外部 CDN，因此完整界面与图表需要网络连接。

## 包内内容

- `index.html`、`web/`：Vue 3 页面、组件模块、模板与工具代码。
- `data/`：展示用 JSON、地图及封面素材。
- `avatars/`、`assets/`：头像、品牌素材和原有样式文件。
- `vendor/`：原有 Vue 3 浏览器运行库。

## 更新日志

### 2026-11-01 ｜ 上线第一天，被图片按在地上摩擦

- 传到腾讯云 EdgeOne Pages，第一次就挂了。挂的理由挺好笑：这站明明是纯静态的，平台非按 Vue 项目给它走一遍流程，然后去找 `package.json`，找不到就报错。就像非要给我的自行车做四轮定位。
- 好容易开起来了，名片一整屏灰色问号。第一反应是我代码写崩了，查了半天才发现：数据里写着头像在 `./avatars/`，可文件压根不在那儿。
- 补了 3,600 多张图，就正常了。**做静态站最难的从来不是写代码，是确认文件真的躺在它该在的地方。**

### 2026-11-06 ｜ 图是坏的，但本地就是看不出来

- 线上鸣谢页的头像继续破，我本地打开却好得很，一度以为是自己眼花了。
- 翻了一圈才发现有 9 个图在骗人：后缀写着 `.webp`，打开一看是 JPEG；后缀 `.png`，里头还是 JPEG。
- 浏览器心大，只看内容不看后缀，所以我本地岁月静好；GitHub 和 CDN 老老实实按后缀认，当场翻脸。
- 用 Pillow 按它自己声明的格式重新存了一遍，文件名和引用一个都没动。9 张图、2 小时、1 条教训：**扩展名是承诺，不是建议。**

### 2026-11-07 ｜ 两万三千个"零"

- 库里 23,498 条记录，获赞和播放都写着 0，其中九千多条粉丝还过千。有粉丝没人赞，这谁信啊。
- 一查，果然是十月批量导入的时候只填了名字和粉丝数，别的格子全空着。
- 那就重采呗，分三批。第一批跑着跑着人家不让问了，歇了半小时。后来发现别急，慢一点反而稳，后两批各跑 35 分钟，一条没错。覆盖率 40.5% → 99.3%。
- 还剩 278 条是真没人赞的：互关小号，没作品。这几个终于不用背锅了。

### 2026-11-08 ｜ 播放量、粉丝，和一次差点团灭的清理

**播放量：**
一开始我以为是 IP 被限了，换节点、换指纹、换代理，折腾五个小时，最后发现流量压根没走 IPv4。IPv6 那条线整个被挡在外面，我前面所有的"加速"都在一条不通的路上踩油门。切回 IPv4 老老实实慢慢跑，33,789 人跑完了，一个没漏。
顺手写了个小代理，省得它又偷偷切回去。

**粉丝：**
3.9 万人的粉丝数，本来估着要一下午，换了条路 27 分钟就跑完了。有些事真不是不能快，是没找对门。

**清理：**
按简介里有没有兽圈词筛人，三轮筛出 371 + 483 个候选。动手之前我多做了一个动作：把他们头像全抓下来拼成图，一张一张看。
看完我沉默了 —— **名单上一半是兽圈的人。**
有人简介就写"蛋仔游戏实况"，头像却是自己画了三年的兽设；有位给《Changed》做曲的老师，因为简介里有"硕士"俩字，被判成学术号了；还有一堆穿兽装实拍的，被归到游戏区。
两轮一共下了 615 位（其中 136 位是真注销了，主页早打不开），后来又把 143 位请了回来。净减 472，**39,461 → 38,989**。
**"看简介猜人"这事儿，比我想的离谱多了。头像比简介诚实。**

### 这几天的总结

- 数据从"一半是零"变成"七成九有播放量"。
- 三次破图，两次是文件名骗人，一次是路径不对。
- 最大的收获不是跑了多少数据，是学会了删之前先看一眼图。
- 这些总结是AI写的，这AI开智了还是个智人，会写总结了（这句是人写的）。
