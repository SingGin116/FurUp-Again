## 用法

安装 Python 3，解压后在本目录打开终端，运行：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

浏览器打开 <http://127.0.0.1:8000/>。终端按 Ctrl+C 停止。

不要直接双击 `index.html`，浏览器会限制 ES modules 和 JSON 加载。
前端不需要 npm 安装、构建步骤、后台服务、登录或密钥。
Tailwind、ECharts 和字体使用原有外部 CDN，因此完整界面与图表需要网络连接。

## 包内内容

- `index.html`、`web/`：Vue 3 页面、组件模块、模板与工具代码。
- `data/`：展示用 JSON、地图及封面素材。
- `avatars/`、`assets/`：头像、品牌素材和原有样式文件。
- `vendor/`：原有 Vue 3 浏览器运行库。

## 更新日志

### 2026-11-01 ｜ 上线，以及一场和图片的搏斗

- 部署到腾讯云 EdgeOne Pages。第一次构建直接失败，原因是框架预设过于自信地选了 Vue，然后 npm 找不到 `package.json` —— 一个纯静态站点被迫接受了一轮工程化体检。
- 页面能打开了，但名片一水儿的灰色问号。查下来不是显示 bug，是头像文件根本没跟着数据一起进来：JSON 里写着 `./avatars/xxx.webp`，磁盘上却在别的目录。
- 补齐 3,600 多张头像后一切正常。**静态站最难的部分从来不是代码，是"文件到底在不在"。**

### 2026-11-06 ｜ 破图真相：9 张图在说谎

- 线上鸣谢页头像继续破，本地却好得很。排查一圈，逮到 9 个"假扩展名"文件：后缀写着 `.webp`，打开一看是 JPEG；后缀 `.png`，内容也是 JPEG。
- 浏览器心大，看内容不看后缀，所以本地岁月静好；GitHub 网页预览和带 `nosniff` 的 CDN 严格按后缀决定 `Content-Type`，于是当场翻脸。
- 用 Pillow 按声明格式重新编码，文件名和 JSON 引用一个都没动。9 张图、2 小时、1 条教训：**扩展名是承诺，不是建议。**

### 2026-11-07 ｜ 23,498 个"零"

- 库里 23,498 条记录获赞和播放双双为 0，其中 9,293 条粉丝过千。有粉丝没点赞，这概率比中彩票还低 —— 真相是 10 月批量导入只写了名字和粉丝数，其余字段留了空。
- 全部重采，分三批。第一批撞上接口限流，冷静半小时；摸清"慢一点反而稳"之后，后两批各 35 分钟零失败。覆盖率 40.5% → 99.3%。
- 剩下 278 条是真的零获赞：互关小号、没作品、也没人点赞。它们终于不用背锅了。

### 2026-11-08 ｜ 播放量、粉丝刷新，和一次差点团灭的清理

**播放量补齐 33,789 人，零失败。**
一开始以为是 IP 被限流，换节点、换指纹、换代理折腾了五个小时，最后发现流量压根没走 IPv4 —— IPv6 出口被整段拒绝，之前所有"加速"都在一条走不通的路上踩油门。切回 IPv4、老老实实限速慢跑，全量跑完。
顺带一个副产品：自己的机器上写了个只走 IPv4 的本地转发小代理，避免程序偷偷切回 IPv6。

**3.9 万人的粉丝数，27 分钟刷完。**
原以为要一下午。换了条更宽松的接口之后速度直接起飞 —— 有些事不是不能快，是没找对门。

**清理非兽圈账号：一次现场教学。**
按简介关键词筛非兽圈账号，三轮筛出 371 + 483 位候选。动手前多做了一个动作：把所有候选的头像拼成图片，一张一张看。
结果令人沉默 —— **待删名单里有一半是兽圈的人**。有人简介只写"蛋仔游戏实况"，头像却是自己画了三年的兽设；有位《Changed》作曲的老师，因为简介里有"硕士"两个字被判定成学术号；还有一批 fursuit 实拍的账号被归进了"游戏区"。
两轮共下架 615 位（其中 136 位账号确实已注销、页面早已打不开），随后又把 143 位请了回来，净减 472 位：**39,461 → 38,989**。
**"看简介猜人"这件事，比想象中不靠谱得多。头像比简介诚实。**

### 这几天的总结

- 数据从"一半是零"变成"79% 有播放量"。
- 三次破图事故，两次根因是文件名，一次是路径。
- 最大的收获不是跑了多少数据，而是学会在动手删之前，先看一眼图。
