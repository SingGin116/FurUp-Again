# FurUp 万事屋：旧版前端源码与数据

这是 FurUp 万事屋旧站的可运行静态前端源码，来自 `Star-Trace-Fur-2-archive-20260226.zip`。
核心代码日期为 2026 年 1 月 18 日；原归档文件日期跨度为 2026 年 1 月 18 日至 27 日。
包名中的 2026 年 10 月 5 日是本次整理日期。数据属于历史快照，不会自动更新。

## 运行

安装 Python 3，解压后在本目录打开终端，运行：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

浏览器打开 <http://127.0.0.1:8000/>。终端按 Ctrl+C 停止。
不要直接双击 `index.html`，浏览器会限制 ES modules 和 JSON 加载。
前端不需要 npm 安装、构建步骤、后台服务、登录或密钥。
Tailwind、ECharts 和字体使用原有外部 CDN，因此完整界面与图表需要网络连接。

- `avatars/`、`assets/`：头像、品牌素材和原有样式文件。
